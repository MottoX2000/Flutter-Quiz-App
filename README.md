# Flutter Quiz App

A modern and interactive quiz application built with Flutter. This app allows users to test their knowledge through various quiz categories and track their progress.

## Features

- Interactive quiz interface
- Multiple quiz categories
- Score tracking
- Modern and responsive UI

## Project Structure

```
lib/
├── main.dart              # Entry point of the application
├── screens/              # Contains all the screen widgets
├── widgets/              # Reusable widget components
├── models/               # Data models
├── services/             # Business logic and services
└── utils/                # Utility functions and constants
```

## Dependencies

- flutter: SDK
- cupertino_icons: ^1.0.8
- flutter_lints: ^5.0.0
